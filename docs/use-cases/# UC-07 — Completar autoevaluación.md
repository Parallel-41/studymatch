\# UC-07 — Completar autoevaluación (Cold Start)



**\*\*Objective:\*\*** Permitir a un alumno sin historial inicial registrar sus competencias previas mediante un quiz.

**\*\*Primary actor(s):\*\*** Estudiante\[cite: 1]

**\*\*Capability area:\*\*** Cold start\[cite: 1]

**\*\*Related issue:\*\*** #9\[cite: 1]



\## Main success scenario

1\. El Sistema detecta a un nuevo estudiante sin historial.

2\. Invita al estudiante a rellenar una autoevaluación.

3\. El Estudiante completa el quiz indicando sus conocimientos.

4\. El Sistema inicializa el perfil del estudiante con estos datos.



\## Domain concepts revealed

\- Student — El alumno nuevo\[cite: 3].

\- SelfAssessment — El quiz o encuesta inicial\[cite: 3].

\- StudentProfile — El perfil que se inicializa\[cite: 3].
